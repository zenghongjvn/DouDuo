# DouDuo 1.3.11 · Duo 定制构建 92

基于上游 `v1.3.11`（`d3fa371`）修改原版界面，目标为 iPhone Duo、iOS 27.1 及以上。保留 AVPlayer / VLC 播放、网页数据桥、消息、评论和原有分享功能。

## 布局

- 三个根页面共用同一个纵向液态玻璃 Dock：**我的 → 私信 → 首页**。首页默认只显示当前图标，点击向上展开胶囊；切回首页收起。展开形态按参考录屏实现，不再使用菜单弹窗；通过系统底部工具栏承载位置，展开状态保存在 TabView 上层，切页不会改变位置。图形显式限制为 24 pt，点击范围至少 44 pt，避免系统工具栏放大图形。
- 更多、频道、搜索固定在分页容器外。更多在左、搜索在右，无玻璃按钮背景，也无横向磨砂顶栏或底栏遮罩。
- 恢复逐条视频内的作者头像、点赞、评论、收藏、空心分享胶囊，随视频上下分页移动；不再把整组互动控件交给系统工具栏缩放。保留此前的 27 pt 图标、7 pt 间距和数字，无额外图标阴影。横向位置继续对齐运行时的侧边状态栏。
- 内屏评论恢复上游 v1.3.11 的宽度规则及列表排版，不再强制 1/3 屏宽。背景延伸至屏幕右缘并保持不透明；打开后完全隐藏视频互动栏和 Dock。标题、相关搜索和首条评论避让系统时间栏，其余正文及底部输入框不再留出贯穿整屏的空白侧栏。
- 评论标题行 44 pt，相关搜索紧接标题下方，输入框贴近底边并避让键盘。首页、关注、我的作品，以及搜索/作者作品和消息跳转播放器复用同一套评论布局；外屏使用统一的系统玻璃 sheet。
- 内屏作者页继续保留左右布局。返回、关注为系统工具栏按钮，位于状态栏下方；作者页隐藏 Dock。作者作品播放器重置父页面隐藏互动栏的环境状态，返回、点赞等按钮恢复；作品评论打开后仍统一隐藏互动栏。
- 简介顺序为 `@作者名 → 文案 → 小字发布时间/声明 → 音乐`。文案默认最多三行，超出后显示展开；短文案没有空展开入口。音乐紧贴进度条，底部信息及进度避开系统栏目按钮。

## 播放与分享

- 捏合放大开启原有“自动铺满宽度”，缩小关闭该设置；松手后回到居中的正常比例，不留下任意缩放或偏移。设置与更多菜单共用 `douyin_autofit_v1`，作用于所有视频入口。
- 视频没有铺满时，统一显示封面模糊背景。AVPlayer、VLC、首帧及高清切换共用画面遮罩，遮掉播放器自身的黑边；画面按原始比例显示。
- 推荐左滑进入作者页，右滑到关注；关注左滑返回推荐。全屏左右滑动不调整进度，底部进度条仍可拖动。
- 长按识别前只允许小范围手指抖动；开始拖动后，本次触摸不能再进入长按倍速。静止长按成功后仍可下滑锁定、上滑解除倍速。长按与点赞的触觉反馈保留。
- 分享面板改为两行：联系人一行，私信/群聊、复制链接、下载、其他分享等操作合并为第二行横向列表。基础高度从 430 pt 减至 300 pt，减少底部留空；与评论共用 32 pt 圆角。下载复用原有保存逻辑，只有点击下载才请求保存；分享继续使用原有官方网页桥。

## 构建与交付

Bundle ID：`com.zenghongjvn.douduo`；版本：`1.3.11 (92)`；最低系统：iOS 27.1；设备范围：iPhone。保留与原版不同的 Bundle ID，不使用旧的原版标识。

执行 `bash scripts/build-unsigned.sh`，输出 `output/DouDuo-1.3.11-build92-Duo-unsigned.ipa` 及 `.sha256`。打包校验版本、标识、最低系统和设备范围；仅在暂存副本中裁剪 VLC 的旧 armv7/armv7s 架构，保留完整 arm64 解码能力，不修改源依赖。该包未签名，供自行签名安装。

VLC arm64 二进制为 35,323,064 字节，上游校验值为 `dce771d1b7e00c21235a390e914e93cbb0829444a749874db2f9c04accccc5e5`。随包附 `.sha256` 校验文件。 成品为 **18,604,812 字节（18.60 MB）**，SHA-256：`92a3073e3f224286995343c9394b01697197150ffbcd8b0f7c3a90ed485d501e`。

## 验证

只使用 iPhone Duo / iOS 27.2；测试静音，不执行真实点赞、关注、评论或消息发送。用户已在 Device Hub 完全展开 Duo，本轮实际内屏为 951 × 669 pt；不使用 iPad 或强制宽屏变量替代。

- `Build92inner-layout.xcresult`：Dock 默认收起、纵向展开、三项顺序、三页位置一致、返回首页收起、固定顶栏及切视频通过。
- 作者 → 作品 → 评论 → 返回作者 → 返回原视频的内屏流程通过；作品页返回、头像、点赞、评论、收藏、分享均可点击，评论展开时全部隐藏。
- 网页端在未登录状态下可能返回空的作者作品列表，作者作品导航测试仅在 DEBUG 用同作者的真实公开视频详情填入一条作品；发布包不含该测试入口。
- 内屏视觉截图由 `simctl --display=3` 捕获。XCTest 默认截图在展开时指向不活动的外屏，不能用其黑色截图判断内屏渲染。

- `Build92inner-acceptance.xcresult`：推荐、关注、我的作品评论布局及内屏作者作品完整往返通过。
- `Build92inner-keyboard-final.xcresult`：三个入口的输入框在键盘出现后完整可见；修复把底部 34 pt 安全区重复加回导致遮挡的问题。检查文字可见高度，避免把只露出细线的输入框误判为通过。
