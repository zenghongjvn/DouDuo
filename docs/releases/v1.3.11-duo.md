# DouDuo 1.3.11 · Duo 定制构建 89

基于上游 `v1.3.11`（提交 `d3fa371`）修改原版界面，目标为 iPhone Duo、iOS 27.1 及以上。保留 AVPlayer / VLC 播放、网页数据桥、消息中心与评论功能。

## 界面与导航

- 头像移入状态栏下方的系统互动栏，点赞、评论、收藏图标适当放大，数字继续显示在下方；原色头像不会被系统模板渲染成白圆。
- 主页、私信、我的共用 Dock 状态，通过同一个 `DYDockToolbar` 声明系统 `.bottomBar`。只让当前栏目提供工具栏，避免缓存页面叠加出多个 Dock。尺寸、左右位置、胶囊材质、触摸范围和纵向布局交给系统；不计算屏幕坐标或绘制自定义 Dock 背景。
- 默认显示当前栏目，点击后在同一系统侧栏展开三个入口，当前栏目排在顶部并标蓝；选择后收起。展开标签与图像一起提供给系统工具栏，保留文字辅助功能。私信、我的根页没有返回按钮，详情页保留返回。
- 搜索右上、更多左上；移除导航背景与顶部滚动边缘磨砂。底部没有整条遮罩背景。
- 简介按 `@作者名 → 文案 → 小字发布时间/声明 → 音乐` 排列。音乐贴近进度条，简介、进度及其拖动范围避开系统侧栏。
- 外屏评论仅使用系统 sheet 的一层玻璃，禁用 sheet 的侧栏留白；相关搜索限制在面板边界内。
- 内屏评论与作者页共用近 1:1 左右分栏，左侧保留当前视频，右侧面板延伸至上下边缘；评论标题居中、输入栏固定底部，面板不再使用悬浮卡片的大圆角。打开右栏时频道、更多和搜索留在左侧视频区域。内屏作者面板复用原生资料与作品列表。
- 全屏左右滑动不再快进：左滑作者，推荐流右滑关注。进度条保留原版相对拖动，竖滑翻页、点击暂停和长按保持原逻辑。

## 标识与构建

Bundle ID 为 `com.zenghongjvn.douduo`，UI 测试为 `com.zenghongjvn.douduo.uitests`。可与原版同时安装；新标识使用独立沙盒，需要重新登录。

需要 Xcode 27.1+ 和对应 SDK。执行 `bash scripts/build-unsigned.sh`。缺少 VLCKit 时脚本下载并校验上游依赖。

输出 `output/DouDuo-1.3.11-build89-Duo-unsigned.ipa` 与 SHA-256 文件。脚本校验 Bundle ID、版本、最低系统、设备范围、框架架构和 ZIP 完整性；不签名、不发布 Release。GitHub Actions 上传同名产物。

## IPA 体积

构建 88 的 IPA 为 49,428,338 字节，上游 1.3.11 为 19,453,330 字节。原因是 `CODE_SIGNING_ALLOWED=NO` 跳过了 Xcode 正常的嵌入框架架构裁剪，额外带入 VLC 的 armv7、armv7s。

构建脚本现在仅在打包暂存副本中保留 arm64，源依赖不变。保留的 VLC 二进制为 35,323,064 字节，其 SHA-256 与上游 IPA 的 arm64 库完全一致：`dce771d1b7e00c21235a390e914e93cbb0829444a749874db2f9c04accccc5e5`。未删减播放或解码功能。构建 89 最终为 **18,584,385 字节（18.58 MB）**，比构建 88 减少 **62.4%**。IPA SHA-256：`2aa3d78497c9de8db89f135f13a1b552db7b78a625bb0482f66e72caab00351b`。
