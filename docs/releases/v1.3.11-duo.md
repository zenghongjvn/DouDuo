# DouDuo 1.3.11 · Duo 定制构建 90

基于上游 `v1.3.11`（提交 `d3fa371`）修改原版界面，目标为 iPhone Duo、iOS 27.1 及以上。保留 AVPlayer / VLC 播放、网页数据桥、消息中心、评论与原有分享功能。

## 界面与导航

- Dock 使用真正的系统 `TabView`，声明顺序固定为 **我的 → 私信 → 首页**。系统决定尺寸、位置、材质以及空间不足时的收起行为；不再用自绘图标或底部工具栏模拟 TabView。三个根页共用相同策略，切页不重排入口，私信、我的根页没有返回按钮。
- 更多、频道、搜索放在视频分页容器外，竖滑换视频时顶栏不消失。更多在左，搜索在右，两者没有玻璃背景；顶部和底部没有横向遮罩。
- 作者头像、点赞、评论、收藏、分享放在每条视频右侧的一组液态玻璃胶囊内，随该视频上下翻页。根据系统侧栏的实际安全区宽度和原有光学边距对齐横向中心，数量保持可见。图标收紧为 27 pt、项目间距 7 pt，点击范围至少 44 pt，移除图标和数字的额外投影；分享使用空心箭头，位于收藏下方。
- 简介按 `@作者名 → 文案 → 小字发布时间/声明 → 音乐` 排列。简介与进度条继续下移，音乐紧贴进度条，文字和拖动范围避开 Dock。
- 外屏评论使用系统 sheet 的单层玻璃；分享弹窗共用 `DDTheme.sheetCornerRadius`，圆角统一为 32 pt。分享采用底部面板，依次显示联系人、分享方式、复制链接等现有操作。更多里的分享、下载、自动铺满宽度设置继续保留；两个分享入口复用原有分享桥。
- 首页、关注、我的作品，以及作者/搜索作品和消息跳转播放器共用评论展示逻辑。外屏共用同一 sheet，内屏共用左右分栏几何，不再由关注和作品页独立创建旧弹层。评论标题行压缩到 44 pt，相关搜索紧接标题下方，输入栏减少底部内边距；分栏高度不重复添加键盘安全区。
- 内屏评论和作者页保留近 1:1 左右布局。评论面板延伸到右侧状态栏所在的屏幕边缘，背景为不透明系统色，不使用玻璃和悬浮卡片圆角；文字与输入框避开系统侧栏。
- 推荐流左滑通过导航栈进入作者整页，内屏则在右栏显示；推荐流右滑进入关注，关注流左滑返回推荐。全屏横滑不拖动播放进度，底部进度条仍可拖动。

## 播放交互

- 双指捏合缩放视频，范围为 0.45–3 倍；只缩放视频，按钮、简介和进度保持原尺寸。缩小时空白区域显示视频封面的模糊背景，切到其他视频时恢复初始比例。
- 双指手势与单指翻页、横滑导航互斥，手势范围避开系统 Dock；原有自动铺满宽度设置决定初始画面布局。
- 进入长按快进时产生轻触觉反馈，按住期间不重复触发；点赞从未点赞切换为已点赞时触发轻反馈，双击点赞复用同一状态逻辑。

## 标识与构建

Bundle ID 为 `com.zenghongjvn.douduo`，UI 测试为 `com.zenghongjvn.douduo.uitests`。可与原版同时安装；新标识使用独立沙盒，需要重新登录。

需要 Xcode 27.1+ 和对应 SDK。执行 `bash scripts/build-unsigned.sh`。缺少 VLCKit 时脚本下载并校验上游依赖。

输出 `output/DouDuo-1.3.11-build90-Duo-unsigned.ipa` 与 SHA-256 文件。脚本校验 Bundle ID、版本、最低系统、设备范围、框架架构和 ZIP 完整性；不签名、不发布 Release。GitHub Actions 上传同名产物。

## IPA 体积

构建 88 的 IPA 为 49,428,338 字节，额外体积来自未签名构建跳过 Xcode 常规架构裁剪，包含了 VLC 的 armv7、armv7s。构建脚本现在只在打包暂存副本中保留 arm64，源依赖不变。

保留的 VLC 二进制为 35,323,064 字节，SHA-256 与上游 IPA 的 arm64 库一致：`dce771d1b7e00c21235a390e914e93cbb0829444a749874db2f9c04accccc5e5`。未删减播放或解码功能。

构建 90 成品为 **18,573,258 字节（18.57 MB）**，SHA-256 为 `f5c5a2c1f4dcb07be91b7e284a727d82e5de17ca8a7570f44012f54ac014f696`，同时提供随包 `.sha256` 文件。

- `Build90Outer2.xcresult` 的四项交互测试通过：原生 Dock 跨页位置、固定顶栏与评论、关注/推荐/作者导航及进度拖动、双指缩放与长按快进、合成联系人分享布局。
- `Build90FinalOuter.xcresult` 的两项复验通过：作者页改为导航栈后，整页进入/返回、关注左滑回推荐、进度拖动及评论布局均通过。
- `Build90ShareFinal.xcresult` 的分享用例通过：统一圆角后的面板、联系人横滑及取消确认；不向真实联系人发送消息。
- `Build90AcceptanceFinal.xcresult` 中 `testSystemBarsDockAndComments` 通过：27 pt 无额外阴影图标、玻璃胶囊与系统 Dock 横向中心对齐、Dock 三页位置一致、顶栏固定及底部信息避让。
- `Build90SharedComments.xcresult` 中 `testMenuCleanupAndFriendForwardWithoutSending` 通过：更多菜单保留原有分享和设置，复制链接确认不被后台联系人状态覆盖。

- `scripts/test_message_navigation.py`、`scripts/test_playback_resume.py` 和 `node scripts/test_native_forward.js`（16 项合成数据测试）通过。
- Release 构建、ZIP 完整性、Bundle ID/版本/最低系统/iPhone 范围、主程序与 VLC 的单一 arm64 架构、VLC 上游哈希校验通过；评论布局测试入口不包含在 Release 二进制中。

界面测试静音，结束终止应用，不执行真实点赞、关注、评论或消息发送。触觉反馈的实机手感未验证。
