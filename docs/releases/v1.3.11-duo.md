# DouDuo 1.3.11 · Duo 定制构建 91

基于上游 `v1.3.11`（`d3fa371`）修改原版界面，目标为 iPhone Duo、iOS 27.1 及以上。保留 AVPlayer / VLC 播放、网页数据桥、消息、评论和原有分享功能。

## 布局

- 首页默认只显示一个原生系统菜单按钮，点开依次为 **我的 → 私信 → 首页**；返回首页重新收起。尺寸、位置、玻璃材质由系统工具栏管理，展开样式为系统菜单。私信、我的保留真正的系统 `TabView`，根页没有返回按钮。采用此区别是因为 `TabView` 的公开压缩接口只在空间不足时生效，不能强制指定首页折叠；用户已确认首页使用系统菜单。
- 更多、频道、搜索固定在分页容器外。更多在左、搜索在右，无玻璃按钮背景，也无横向磨砂顶栏或底栏遮罩。
- 当前视频的作者头像、点赞、评论、收藏、空心分享箭头为一组液态玻璃胶囊，由系统工具栏安排在侧边状态栏下方。数字保留，27 pt 图标、7 pt 项目间距、至少 44 pt 点击范围，无额外图标或数字阴影。
- 内屏评论占物理屏幕宽度约 1/3，包含右侧系统栏区域；背景为不透明系统色。评论打开时隐藏 Dock，互动胶囊放在最右侧状态栏内，左边视频不再重复显示互动按钮。正文、搜索、输入框避开侧栏，视频与进度条可利用腾出的宽度。
- 评论标题行 44 pt，相关搜索紧接标题下方，输入框贴近底边并避让键盘。首页、关注、我的作品，以及搜索/作者作品和消息跳转播放器复用同一套评论布局；外屏使用统一的系统玻璃 sheet。
- 内屏作者页继续保留左右布局。返回、关注为系统工具栏按钮，位于状态栏下方；作者页隐藏 Dock。
- 简介顺序为 `@作者名 → 文案 → 小字发布时间/声明 → 音乐`。文案默认最多三行，超出后显示展开；短文案没有空展开入口。音乐紧贴进度条，底部信息及进度避开系统栏目按钮。

## 播放与分享

- 捏合放大开启原有“自动铺满宽度”，缩小关闭该设置；松手后回到居中的正常比例，不留下任意缩放或偏移。设置与更多菜单共用 `douyin_autofit_v1`，作用于所有视频入口。
- 视频没有铺满时，统一显示封面模糊背景。AVPlayer、VLC、首帧及高清切换共用画面遮罩，遮掉播放器自身的黑边；画面按原始比例显示。
- 推荐左滑进入作者页，右滑到关注；关注左滑返回推荐。全屏左右滑动不调整进度，底部进度条仍可拖动。
- 长按识别前只允许小范围手指抖动；开始拖动后，本次触摸不能再进入长按倍速。静止长按成功后仍可下滑锁定、上滑解除倍速。长按与点赞的触觉反馈保留。
- 分享面板改为两行：联系人一行，私信/群聊、复制链接、下载、其他分享等操作合并为第二行横向列表。基础高度从 430 pt 减至 300 pt，减少底部留空；与评论共用 32 pt 圆角。下载复用原有保存逻辑，只有点击下载才请求保存；分享继续使用原有官方网页桥。

## 构建与交付

Bundle ID：`com.zenghongjvn.douduo`；版本：`1.3.11 (91)`；最低系统：iOS 27.1；设备范围：iPhone。保留与原版不同的 Bundle ID，不使用旧的原版标识。

执行 `bash scripts/build-unsigned.sh`，输出 `output/DouDuo-1.3.11-build91-Duo-unsigned.ipa` 及 `.sha256`。打包校验版本、标识、最低系统和设备范围；仅在暂存副本中裁剪 VLC 的旧 armv7/armv7s 架构，保留完整 arm64 解码能力，不修改源依赖。该包未签名，供自行签名安装。
