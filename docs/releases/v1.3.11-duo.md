# DouDuo 1.3.11 · Duo 定制构建 88

基于上游 `v1.3.11`（提交 `d3fa371`）修改原版界面。目标为 iPhone Duo、iOS 27.1 及以上。保留上游 AVPlayer / VLC 播放、网页数据桥、登录态、消息中心与评论功能。

## 界面

- 点赞、评论、收藏交给系统竖向工具栏布局，位于状态栏下方，图标下保留数量。系统竖向工具栏只提取图像，因此数量与 SF Symbol 一起绘制为模板图像；辅助功能仍读出操作和数量。
- 下方 Dock 默认只显示当前栏目，点击系统菜单切换主页、私信、我的，选中后收起。使用系统工具栏菜单保证默认收起，TabView 保留页面状态；不使用固定纵向坐标。
- 搜索在右上，更多在左上；两个顶部按钮隐藏共享玻璃背景。
- 视频维持原版比例和全幅播放。文案及进度条按运行时侧栏安全区留出空间，展开标题也避让 Dock。
- 评论使用原生 `.glassEffect(.regular)`；保留原版宽屏左右分栏、窄屏评论 sheet 和折叠布局算法。

## 构建

需要 Xcode 27.1+ 和对应 iOS SDK。执行 `bash scripts/build-unsigned.sh`。缺少 VLCKit 时脚本下载并校验上游依赖。

输出 `output/DouDuo-1.3.11-build88-Duo-unsigned.ipa` 与 SHA-256 文件。脚本校验版本、最低系统、设备范围和 ZIP 完整性；不签名、不发布 Release。GitHub Actions 沿用仓库的 xcode-27 runner 并上传同名产物。
