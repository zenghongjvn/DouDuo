# DouDuo 1.3.12

1.3.11（87）之后的两处入口修正，外加爱思助手签名失败的排查说明。包为**未签名 IPA**，需要自行签名安装。

## 关注与直播入口
- **关注页只放关注作品**：不再在顶部挂一排「直播中」头像，刷关注不再被直播入口打断。
- **直播页不再重复挂关注头像条**：看直播时页面更干净；关注主播的开播列表统一走直播页的「我的关注」按钮，点开即是完整列表。

## 安装：爱思助手签名失败先登录一次 iCloud
- 很多人卡在「签名失败 / 验证失败 / 无法请求签名」，原因是准备签名的 Apple ID 从未在该设备上登录过 iCloud。
- 处理办法：在手机 Safari 打开 [icloud.com](https://www.icloud.com)，用**同一个 Apple ID** 登录一次，按提示同意条款、完成双重认证，然后回爱思助手重新「开始签名」。
- README 的「方式一：爱思助手」教程已补上这条提示，位于「添加 Apple ID」之后。
