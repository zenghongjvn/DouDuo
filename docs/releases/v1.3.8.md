# DouDuo v1.3.8 · 原生转发浮层、朋友缓存与右侧栏调整

## 转发给抖音朋友（本次新增）
- 转发界面改成和原版一致的原生浮层：标题「分享给」、右上关闭、上排横滑好友头像昵称、下排横滑圆形操作，官网页面只在后台提供数据与发送能力。
- 好友来自当前登录账号的真实分享列表，按账号隔离；未接入的「推荐 / 日常 / Dou+」不显示，不做假入口。
- 发送的是官方作品卡片（type 8 / aweType 800），不是普通链接粘贴。
- 发送结果以官方业务回调为准：成功立即结束、失败明确提示；识别不到官方组件时直接不发送，不自动重发。

## 缓存与增量
- 朋友列表、@ 朋友、私信会话、互动通知改为 App 本地缓存：打开即显示上次的数据，后台只同步变化的部分。
- 私信会话按会话 ID 做增量差异，对方改昵称不会再冒出重复会话；没有变化时不写盘、不刷新界面。
- 转发浮层复用自己的网页上下文，第二次打开不再重新加载整页。

## 弹幕
- 弹幕限制在画面上方三分之一区域，不影响画面主体。
- 新增稀疏 / 标准 / 密集三档密度，默认开启，并对 10 秒内重复的同样文本去重。

## 直播
- 直播分类改为接入网页真实分区：精选、关注、游戏、聊天、音乐、二次元、舞蹈、文化、生活、运动；删掉没有真实数据来源的占位入口。
- 修复直播发言：接入官网编辑器 Enter 流程并等待真实业务回执，不再出现「看着发出去了其实没发」的假回显。
- 直播页去掉独立「游戏专区」按钮，游戏一级分类保留。

## 界面与操作
- 右侧动作栏顺序对齐原版：赞 → 评论 → 收藏 → 搜索，并收紧图标间距。
- 播放信息补充发布时间与 AI 生成声明，旧缓存数据也能正常显示。

## 设置与推荐
- 精简「更多」菜单层级：当前视频操作、弹幕、播放设置、缓存管理、账号与登录、关于分开收纳。
- 竖屏比例不再手动调节，内部固定 70%；保留横屏「仅横屏」规则，候选素材不足时自动放宽。

## 从 1.3.4 起的累积更新
- **1.3.5**：缓存改为整条缓存并修复签名跳转导致的 403；关注页未登录不再塞推荐兜底；短视频占比区分竖屏与横屏。
- **1.3.7**：消息中心重做（朋友头像栏、互动 / 粉丝 / 系统通知分类、陌生人消息独立入口、原生会话列表）；评论支持抖音官方表情 214 个、@ 关注列表、评论配图与贴纸放大；直播新增「发现更多」与左缘右滑返回；顶栏增加独立的「我的」「信息」入口。

## 安装
- 支持 iOS / iPadOS 17.0 及以上。
- 下载附件 `DouDuo-1.3.8-unsigned.ipa`，用爱思助手 / Sideloadly 等工具自行签名；**未签名原包不能直接安装**。
- 免费 Apple ID 签名通常 7 天有效，到期需重新签名；同账号覆盖安装，不要先卸载。
- GitHub 下载：https://github.com/81199000/DouDuo/releases/latest
- Gitee 国内下载：https://gitee.com/remon8/douduo/releases
- 完整图文教程见仓库 README「下载与签名安装」。
