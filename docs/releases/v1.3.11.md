# DouDuo v1.3.11 · 消息中心主从导航、分享视频跳转与界面优化

本次整合自上一公开版 **v1.3.10（74）** 之后的累积更新，发布构建号 **86**。

## 消息中心
- **统一主从导航**：互动、粉丝、系统、陌生人与朋友/群聊统一选择和返回层级；支持双栏时保留左侧列表，在右侧切换详情，窄屏显示当前详情。
- **会话排序**：按最后消息时间倒序显示，兼容今天、昨天、月/日等实际时间格式。
- **更自然的返回**：陌生人聊天先返回陌生人列表，再返回消息列表；分类和会话增加选中高亮，已访问的通知分类保留筛选状态。
- **聊天内分享视频跳原生播放**：从真实 IM 分享消息提取作品 ID，点分享卡片进入原生播放器；拒绝把用户 ID、消息 ID 等任意长数字误当视频 ID。
- **聊天视觉整合**：统一网页聊天与原生列表的黑色背景，去掉灰色盒状外框；保留真实聊天内容与输入、附件、表情等网页控件，不改发送协议。
- **窄屏遮挡修复**：详情显示时同步隐藏并禁用底层列表，避免选中行和头像从底部/系统侧栏漏出，或被无障碍误命中；聊天 WebView 保持常驻。

## 评论与通知
- 评论通知新增**回复按钮**，长评论可展开全文，点击评论可进入视频并定位相应评论。
- **评论配图**：带图评论通知显示缩略图；旧缓存自动作废重取，无需手动清数据。
- 通知解析逐条容错，单条异常数据不再拖垮整个列表。
- 竖屏评论区固定半屏，横屏关闭键避让右侧时间，展开更多回复增加间距，减少误触。

## 播放界面
- 右侧按钮顺序保持**点赞 → 评论 → 收藏 → 搜索**，下方独立“更多”。
- 图标纵向间隔由 6pt 增加到 **12pt**，主胶囊与“更多”间隔由 10pt 增加到 **16pt**；按钮和图标本体大小不变。
- 展开布局按系统栏运行时几何定位，并依据实际设备截图补充光学位置校正；收起布局不追加该校正。
- 更新为抖音风格的 **duo** 图标。

## 直播与播放稳定性（87，合并社区 PR #8）
- 合入 **@kikozheng27-creator** 的 PR #8：直播播放门禁统一管理短视频与直播的声音——分享浮层等覆盖层暂停不再被「后台播放」开关绕过；短视频后台播放、直播后台声音、音频会话释放各走自己的策略。
- 直播切换房间时不再被旧的恢复逻辑打断；VLC 画面渲染挂载与恢复条件收紧，减少切台黑屏/转圈。
- 关注页「直播中」入口改用独立逻辑文件并补充匿名统计（不含房间、流地址或用户标识），附带 5 个直播回归脚本。
- 额外修复两处社区 PR #5 指出的问题（只取小修，不引入其独立音频引擎）：用户手动暂停后，切后台再回前台不会自动开播；锁屏/控制中心显示的是本条实际速度（含长按临时 2 倍），不再是设置里的全局速度。

## 验证与仍需确认的边界
- 本轮消息分类/聊天/通知视频返回相关真实模拟器 UI 回归 **3 项通过、0 失败、0 跳过**；操作栏只读 UI 回归 **1 项通过、0 失败、0 跳过**，三处相邻间距实测均为 12pt。
- 合入 PR #8 后重跑：16 个脚本回归（消息导航、聊天外观、右栏几何、直播逻辑/门禁/画质/分类/直播条/直播源/关闭键/键盘布局、分享卡片、会话差异、通知配图、评论发送、隐藏页媒体）全部通过；模拟器 UI 回归 3 项再次通过；模拟器与 iPhoneOS 构建成功。
- 续播规则新增可编译回归：后台打断会续播、手动暂停保持暂停。该规则是纯逻辑验证，真机锁屏与耳机切换仍需实测。
- 本地回归覆盖真实脱敏 IM 分享样本、错误 ID 拒绝、通知图片、会话差异同步、Swift 导航状态、聊天 CSS 几何及操作栏几何。合成/离线回归不作为真实账号发言或折叠姿态验收。
- 本轮测试未输入、发送私信、点赞、收藏或关注；安装与版本回读不代表这些账号写操作已重新验收。
- **展开操作栏与系统信号图标的最终视觉对齐、跨姿态连续切换，以及非顶部通知列表滚动恢复仍未完成全面真机验收。** 旧图的校准结果不等于新包已经对准；不宣称与官方客户端完全一致。
- PR #8 的直播恢复/切台行为只做了编译与脚本回归，尚未在真机连续切台、弱网和后台直播场景验收；PR #5 的独立音频引擎按风险暂缓，未并入。
- 本包仍依赖抖音网页接口，接口改版或风控可能要求重新登录/网页验证；搜索仍仅支持接口返回的第一页。
