# DouDuo 1.3.14

1.3.13（91）之后的性能修复与折叠屏布局修正。包为**未签名 IPA**，需要自行签名安装。

## 修复 1.3.13 滑动卡顿
- **正常速度（1x）改回系统原生声音**：1.3.13 合入的「倍速不断声」独立音频引擎会在主线程上解码声音，并在预加载时为后面几条视频提前解码，滑动时容易掉帧。现在只有把播放速度设成 0.75 / 1.25 / 1.5 / 2 倍时才启用该引擎；1x 下不再解码，也不再预热音频。
- 在「更多」里切换速度时，当前视频会就地切换声音通路，从当前位置接着放，不用滑走再回来。
- **简洁 / 极简模式的进度环不再拖累整屏**：进度环每 0.25 秒更新一次，1.3.13 里这个更新会让整个首页一起重新计算；现在只重画进度环本身。

## 半折叠布局
- 推荐页半折叠时，视频和评论按真实折痕位置切分（与直播分屏同一套几何），折痕两侧都不压内容；书本姿态下评论区不再被右上角状态栏挤得偏左。

## 验证与仍需确认的边界
- 模拟器：1x 下 2 次绑定全部走原生声音、1.5x 下全部走独立引擎；简洁模式与默认模式均正常起播。
- 半折叠布局已在 iPhone Duo 真机上看过竖屏与横屏两种姿态。
- 模拟器 CPU 采样波动较大，**本版未能用数据证明真机上的流畅度提升幅度**，请升级后反馈。
- `test_live_categories.py` 仍失败，该问题在本版之前已存在。
