# DouDuo 1.3.12 · Duo 定制构建 94

继续基于 build 93 已合并的上游 v1.3.12。Bundle ID 为 `com.zenghongjvn.douduo`，iOS 27.1+，仅面向 iPhone Duo，交付未签名 IPA。

## 布局调整

- 恢复真正的系统 TabView，顺序为我的、私信、首页。搜索及当前视频互动栏参与系统侧栏布局，在空间不足时优先压缩 TabView；点击收起的当前栏目展开系统选择器。
- 搜索独立放在状态栏下方。互动栏在系统工具栏内靠近 Dock 排列；保留 27 pt 图标、计数、34 pt 作者头像和紧凑胶囊。使用自身工具栏视图的公开窗口坐标测量高度，不读取系统私有视图层级。内屏竖向没有系统竖栏时，互动栏独立竖排，避免落入横向底栏。
- 评论打开时统一隐藏底层 TabView 与视频工具栏，覆盖内屏分栏和外屏弹窗两种路径。修复先展开系统 Dock、再打开和关闭评论时，展开选择器残留在视频上方的问题。
- 内屏评论继续使用原版宽度与纯色背景，移除互动栏及 Dock，相关搜索仍在顶部。修正左右分栏边界被误画成评论中部横线的问题。
- 评论列表与输入区域改为独立布局并裁切，滚动图片和文字不再透入小屏输入区。输入框最小高度 44 pt，增加底部内边距，大小屏统一抬高。
- 小屏评论和分享的玻璃面板铺满左右边缘并贴底。大屏分享位于右下角，宽度为全屏一半、底部无缝隙。两屏共享相同按钮尺寸和内容自适应高度，保持两行布局。
- 分享操作加入颜色区分：私信红、群分享橙、复制蓝、下载绿、其他分享紫。保留既有复制、保存、官网联系人及发送确认逻辑。
- 作者名采用加粗亮白，正文较轻并最多三行，发布时间、声明与音乐采用更小的灰色文字；音乐继续贴近进度条。
- 内屏竖向保留系统横向 Dock 的完整底部安全区，简介及进度条不再压到 Dock；侧栏布局仍保持贴近屏幕底部。

## 验证记录

仅使用 iPhone Duo / iOS 27.2 的实际外屏、展开内屏与内屏竖向，不使用 iPad 或强制宽屏代替。测试静音，不发送真实私信/评论，不操作真实点赞或关注。

- 上游关注/直播布局 3 项、关注直播状态逻辑 2 项、播放恢复策略检查通过。
- 系统 Dock：内屏 951×669 pt 和外屏 466×678 pt，分别连续三次打开、关闭评论；第三轮先手动展开原生选择器。关闭后均恢复单个首页按钮，并保持互动胶囊在上方。内屏同时验证我的／私信／首页切换、顶部频道固定和切换视频。
- 内屏竖向 669×951 pt：使用 Device Hub 实际旋转，验证互动栏独立竖排，简介和进度条与横向 Dock 不相交。
- 评论：推荐、关注、我的作品共用面板检查通过；内屏原版分栏宽度、相关搜索在上、隐藏互动及 Dock、作者作品返回控件检查通过。外屏面板三边贴齐、列表裁切、输入区域高度与留白检查通过。
- 分享：内屏右下角宽度为全屏一半，外屏全宽，底部均无缝隙；两行按钮和最小底部留白检查通过。联系人布局用明确标注的 DEBUG 合成数据，不发送消息，发布包不包含该入口。
- 本轮使用未登录态查看公开作品；未验证登录后的评论／私信发送。模拟器输入区已检查聚焦与遮挡，硬件键盘连接下不将其视为软键盘覆盖测试。
- 自动化旋转不能改变此 Duo 运行时的实际显示姿态；竖向用例须先在 Device Hub 旋转。测试完成后已关闭本次 Duo 模拟器及 Device Hub。
