# DouDuo 1.3.12 · Duo 定制构建 95

基于已合并上游 v1.3.12 的 build 94。Bundle ID 保持 `com.zenghongjvn.douduo`，最低 iOS 27.1，仅 iPhone Duo，交付未签名 IPA。

## 本轮调整

- 保留系统 TabView 与原生收起/展开选择器。选中项使用与开关一致的主题红色；各页面恢复默认 tint，互动、搜索、清屏、分享等按钮保留各自原色。
- 修复侧栏高度反复反馈导致的闪动：仅测量独立的清屏工具栏锚点，尺寸稳定后更新互动栏；返回评论或作者页时保留已测量高度，避免临时展开 Dock。内外屏含实时活动占位时保持头像、互动胶囊和 Dock 分离。
- 搜索固定在右上角，清屏按钮使用 eye.slash / eye。清屏后隐藏其他 App 控件、简介、进度与弹幕，退出清屏恢复原布局。
- 头像下新增小号关注加号，调用既有网页关注接口；已经关注时隐藏。首页与作者页共享关注结果，账号重新加载时清除关系缓存。
- 中间 40% 长按打开统一玻璃视频设置，两侧各 30% 长按倍速；移动超过阈值后不再误判长按。设置分组默认展开，选中项背景更深；倍速、推荐占比与弹幕密度采用统一分段按钮。第一排仅保留各按钮背景，去掉整排大背景。
- 更多菜单直接列出刷新推荐、缓存、账号与登录、关于；播放偏好和弹幕设置统一迁入长按菜单，分享及下载继续从分享面板进入。
- 评论顶部去掉横条，评论数量与关闭按钮同排，相关搜索紧接标题下方。标题下拉或列表位于顶部时下拉可关闭，列表中部滑动仍保持滚动。内屏继续保留原版评论宽度和纯色背景。
- 评论、分享、视频设置的面板外部不再添加阴影蒙版。外屏三边贴齐，内屏分享位于右下角、宽度为全屏一半。
- 简介与进度条整体上移并保持音乐与进度条间距；分享第二行、评论输入框按物理窗口底部安全区避让系统退出条，背景仍铺到屏幕底边。输入框在软键盘出现时继续避让键盘。
- 顶栏按物理窗口安全区布局，避免内屏旋转后重复叠加导航栏高度。竖向系统侧栏下的简介与进度条只使用物理底部安全区，消除旋转后遗留的横向底栏留白。
- 清屏时为 AVPlayer 接入系统自动画中画；普通播放保留原来的退出暂停策略。若系统拒绝启动则回到原有后台播放策略；关闭小窗保持暂停，返回 App 恢复同一个视频。

## 清理

删除已停用的旧弹幕菜单、更多菜单转发包装层、无人使用的弹幕请求桥、重复菜单状态、未使用的搜索回调和旧侧栏几何计算。移除依赖 build 84 布局的过期静态检查，保留推荐策略的可执行测试，原生菜单/侧栏由 Duo UI 用例验证。清除已跳过账号写入测试后不可达的代码。未删除历史交付文件或用户数据。

## 验证与边界

- 仅使用 iPhone Duo / iOS 27.2 的真实外屏和展开内屏，测试静音。
- 外屏 466×678 pt：清屏只保留一个退出按钮；评论与分享贴边；输入框与滚动内容分离、聚焦键盘避让；连续三次评论关闭、三次作者返回，Dock 恢复收起且互动不进省略菜单。
- 内屏 951×669 pt：相关搜索与评论下拉关闭、右下半屏分享、连续评论/作者返回、系统 Dock 三个页面切换、长按分区及设置迁移检查通过。包含临时测试实时活动，测试应用不进入 IPA。
- 内屏竖向 669×951 pt：互动栏与横向 Dock 分离，简介和进度条不相交；通过 Device Hub 实际旋转回横向后，顶栏回到原位、底部不残留竖向 Dock 留白。
- 推荐策略 64 组旧偏好/方向组合、推荐池保留与稀缺回退、后台恢复策略、直播状态策略检查通过。
- 更新旧倍速测试到当前长按菜单后，全局速度与临时锁定速度互不污染的用例通过；拖动后停留不误触倍速的用例通过。
- 追加的双指自动化未通过：此 Duo 运行时在透明手势层上出现不可命中的区域、方向映射异常；改用窗口后仍未稳定通过铺满切换和菜单定位。因此不把双指缩放列为本轮已验证项，保留既有缩放实现，仍需实机确认。
- 不执行真实点赞、关注、评论、私信写操作。分享联系人布局仅使用明确标记的 DEBUG 合成数据；发布包不含测试入口。
- 当前 Duo 模拟器的 `AVPictureInPictureController.isPictureInPictureSupported()` 返回 false，因此画中画用例明确跳过，未声称真机小窗已验证。真机还需检查系统画中画开关；VLC 兜底播放不启用该 AVPlayer 小窗路径。
