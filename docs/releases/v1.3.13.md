# DouDuo 1.3.13

1.3.12（90）之后的一次集中更新：折叠屏直播、三档界面模式、倍速与播放菜单整理，并合入三位社区贡献者的 PR。包为**未签名 IPA**，需要自行签名安装。

## 三档界面模式（更多 → 界面）
- **默认**：顶部「关注 / 推荐 / 直播」文字页签 + 原有右侧按钮栏，和 1.3.12 一致，升级后不用适应。
- **简洁**：页签收进右侧功能栏的圆形入口（合入 PR #12），搜索放进入口的展开菜单；视频进度画在入口外圈，不再占底部进度条。
- **极简**：在简洁基础上隐藏作者和标题。手指按到入口就显示作者标题，单击弹菜单时也显示，松手或菜单收起后消失；长按只看标题，不弹菜单。
- 入口外圈进度环与右侧胶囊同宽，入口到胶囊的间距与胶囊到「更多」一致；未读消息红点改放在入口菜单的「消息」一行。

## 折叠屏直播（合入 PR #11）
- 半折叠自动分屏：桌面模式上放画面、下放互动区；书本模式左画面、右互动区；横屏画面避开状态栏。
- 直播封面生成柔和的环境光背景，只留在互动区内。
- 「更多」里新增**分屏 / 整屏**：内屏展开时随时可点，不需要半折叠。
- 关注主播的开播头像条放到**直播页顶部**，替换原来的「我的关注」按钮，点开一排头像，点哪个进哪个；关注页仍只放关注作品。
- 直播评论区提速：视频出画后提前在后台加载，进房时多半已连上；评论网页不再下载图片、字体和媒体；翻台时预热相邻直播线路。

## 播放与菜单
- **倍速改为点开选速度**（0.75 / 正常 / 1.25 / 1.5 / 2），放在「更多」第一层；设置里重复的播放速度、自动连播、自动铺满宽度已删除。
- **修复改了倍速当前视频不变速**：预加载的播放器里保存的是创建时的旧倍速，会把你刚改的速度拉回去，只有滑到下一条才生效。现在每次读取当前设置。
- **自动铺满**按钮放在右侧栏搜索下方，不变色，靠图标形态区分：向内箭头 = 铺满中，向外箭头 = 完整画面。
- 长按加速：开始时震动；加速期间按钮和信息淡出；手指按在右侧按钮或头像上也能触发；松手后不再误暂停；右侧按钮五个对齐、间隙整体缩 1/4。
- 主播头像右下角加关注标记：已关注绿色对勾，未关注红色加号。
- 设置 → 关于 显示当前版本号。

## 倍速不断声（合入 PR #5）
- 变速时声音由独立音频引擎播放，改速度不再顿一下、不爆音；读不到音轨时自动回退原生声音。
- **本版修了合入时发现的一个崩溃**：音频包在不连续内存里时，解码喂包会读越界闪退；现在先拷成连续内存再喂给解码器。
- 开「后台播放」时按系统前后台状态判断，回前台续播沿用已有的暂停规则。
