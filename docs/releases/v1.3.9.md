# DouDuo v1.3.9 · 直播页顶部关注主播直播条

## 直播
- 「关注的人正在直播」头像排从关注页移到**直播页顶部**：进直播就能看到，贴在「发现更多」那一行下面。
- 头像排的用法跟官方一致：进入展开，**上滑换到下一个直播间后收成「N 个直播」胶囊**，点胶囊再展开。
- 点任意头像直接进入该主播的直播间，不用再翻「发现更多」。
- 头像排的位置按顶栏实际下沿计算，不写死安全区数值，折叠屏外屏 / 内屏都不会压住分类行。

## 关注
- 关注页顶部不再显示直播头像排，回归纯关注流，只有关注页本身的内容。

## 安装
- 支持 iOS / iPadOS 17.0 及以上。
- 下载附件 `DouDuo-1.3.9-unsigned.ipa`，用爱思助手 / Sideloadly 等工具自行签名；**未签名原包不能直接安装**。
- 免费 Apple ID 签名通常 7 天有效，到期需重新签名；同账号覆盖安装，不要先卸载。
- GitHub 下载：https://github.com/81199000/DouDuo/releases/latest
- Gitee 国内下载：https://gitee.com/remon8/douduo/releases
- 完整图文教程见仓库 README「下载与签名安装」。
