# DouDuo v1.3.7 · 消息中心升级、评论增强与直播发现

## 消息与私信
- 重做消息中心，增加朋友头像栏，以及互动消息、粉丝消息、系统通知等分类入口。
- 私信首页改为原生会话列表，点击会话打开独立聊天页面（聊天内容仍复用抖音网页）。
- 新增陌生人消息分类，按关注关系归类，避免与普通会话混排。
- 修复陌生人多会话打开、标题兜底及误跳其他会话等问题。
- 增加消息本地缓存与增量同步；退出已查看分类后更新已读状态。

## 评论
- 新增抖音表情面板，支持选择表情发表评论，并将评论中的表情文本显示为表情图。
- 新增 @ 用户选择面板，横排展示朋友头像。
- 支持显示评论及回复中的配图和贴纸，点击可放大查看。

## 直播
- 新增可展开、收起的「发现更多」入口，展示正在开播的关注主播。
- 增加精选、关注及游戏专区入口；其他尚未接入数据的分类会明确提示，不代表已支持。
- 调整直播间返回按钮，增加左缘右滑返回；清屏状态支持返回恢复。

## 界面与操作
- 顶栏增加独立的「我的」和「信息」入口，优化折叠屏摄像头避让及点击区域。
- 展开评论栏时，顶栏随视频区域收窄并居中。
- 优化个人页、消息页及视频详情的返回操作；打开覆盖页面时暂停视频。
- 「我的作品」列表增加播放量显示。

## 安装
- 支持 iOS / iPadOS 17.0 及以上。
- 下载附件 `DouDuo-1.3.7-unsigned.ipa`，使用爱思助手、Sideloadly 等工具自行签名安装。
- 免费 Apple ID 签名通常 7 天有效，到期需要重新签名。
- [完整安装教程](https://github.com/81199000/DouDuo#安装)
