# 1.3.3（build 43）选择性集成与验证

## 来源与范围

选择性采用社区 PR #2（95f1c8079ea81e405e2ac6397010ca87a8e577b9）的直播专区、关注直播入口、清屏、网页播放器兼容与部分 VLC 生命周期处理；不整包合并。

保留当前推荐接口、横竖比例设置、已有播放页布局、快进缩略图和直播发言/网页入口。不引入强制重置用户偏好的迁移代码。

补入 PR #1 提到的作者主页打开时暂停推荐/关注底层视频。

## 修正

- VLC 渲染层固定在直播列表背景，不再随分页 cell 拆建；暂停/停止与自然播完分开处理，换流清零旧进度状态。
- 保留直播 3000ms 缓存；不宣称 600–800ms 缓存能普遍实现秒开。
- 仅实际视频输出/播放进度判定起播，删除定时隐藏加载提示的假成功路径。
- 专区请求复用 DouyinBridge，但使用按需加载的 live.douyin.com 同源网页 SDK；仍共享默认 WebKit 登录存储。首个跨域版本真机失败，已替换，不能把 HTTP -1 等同于未登录。
- 专区数据和分页游标增加代际保护，旧请求不得覆盖新分类。
- 失败页同时提供重试、网页版/登录和返回推荐直播；加载中也保留网页入口。
- 播放页去掉关注按钮，作者主页关注按钮保留；标题默认一行，可展开/收起。
- 合屏右栏缩窄至42pt，展开保持原尺寸；对齐系统信号栏中心列。
- 评论列表下方新增相关搜索，来自网页 suggest_words 的 related_search 数据；无数据不展示，点击复用原生搜索组件。

## 实际验证

- Debug 真机编译成功。
- 模拟器 UI：testCompactLayoutAndAuthorEntry、testMoreMenuLayout 均通过；截图验证无播放页关注按钮、单行标题展开/收起、窄玻璃栏及作者主页关注入口。
- 真机三次直播检测均 hasVideoOut=true，drawable 对象保持不变；该轮等待约2.48s、4.96s、7.04s。这是一次网络样本，不是时延保证。
- 真机英雄联盟专区返回15个房间；关注直播接口返回8个直播间；相关搜索返回6词。条数随平台实时变化。
- 模拟器打开评论，实际出现相关搜索词；点击其中一个后，原生搜索输入框带入对应词。
- 正式 Release 归档和安装状态以实际工具回读为准，以上不等于已对外发版。
